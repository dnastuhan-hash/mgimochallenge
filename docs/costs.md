# Время, расходы, ошибки и помощь человека (демо-проект `family-connect`)

## Как измеряли

- **Время** — по меткам `projects/family-connect/log.jsonl` (хук пишет каждое действие) и по коммитам.
  Ожидание человека из времени работы агента исключено.
- **Токены главного агента** — оценки, записанные в `sfp log` после шагов 07–11. Для шагов 01–05 оценки не
  записывались: тогда учёт ещё не был включён в процесс, и это наш промах.
- **Токены субагентов** — точные цифры, которые среда сообщает по завершении каждого субагента.
- **Цены** — `tools/pricing.json` (справочник API). Работа шла по подписке Claude Code, поэтому суммы — эквивалент
  API, а не счёт.

| Статья | Модель | Токены | Оценка, $ |

| Критик, шаг 10 | opus | 63 тыс. | ~0,3–0,5 |

| **Итого демо-проект** | | | **≈ 7–8 $** |

`./sfp cost` показывает разбивку по шагам. Точные токены сессии — `/cost` в Claude Code.

**Что дорого и почему:** почти вся стоимость — главный агент на opus, который пишет стратегию и держит контекст
шагов. Проверки на haiku стоят копейки, и именно они ловят большинство несогласованностей. Это подтверждает
маршрутизацию: экономить на суждениях нельзя, на проверке — можно.
