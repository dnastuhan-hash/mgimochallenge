# Сценарий видео (до 10 минут)

Цель: показать сквозной путь демо-проекта — запрос → работа агента → варианты → стратегия → продолжение после
перерыва — и то, чем агент отличается от обычного чата: **проверяемостью**.

**Подготовка:** Claude Code в папке репозитория; терминал крупным шрифтом; в браузере открыт
`projects/family-connect/deliverables/strategy.html`. Чтобы показать живой старт, не трогая демо, создайте учебный
проект: `./sfp init demo-live --title "Живой старт"`. В конце верните активный проект: `./sfp use family-connect`. Папку `projects/demo-live/` после записи удалите
и не коммитьте.
