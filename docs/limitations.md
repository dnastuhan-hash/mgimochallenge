# Заявленные возможности и их ограничения

## Форматы материалов

| Формат | Как | Ограничение |
|---|---|---|
| PDF | `extract.py` через `pdftotext` или `pypdf` | Сканы без текстового слоя не распознаются (OCR нет); таблицы в PDF могут разъехаться — агент сверяет числа с исходником |
| DOCX, XLSX, CSV, HTML, TXT, MD | `extract.py`, только стандартная библиотека | Формулы XLSX — только значения; сложное форматирование теряется |
| Веб-страницы | `fetch_source.py` — снимок с хэшем | Только разрешённые домены; страницы, которым нужен JavaScript, могут извлечься неполно |
| Изображения, скриншоты, макеты | Read (мультимодально), субагент `ux-reviewer` | Замечания — только о видимом в материале; сценарии за кадром не додумываются |
| Видео | разбор по **кадрам**: `ffmpeg -i video.mp4 -vf fps=1/5 frame_%03d.png` → кадры как изображения | Звук и движение между кадрами не анализируются; ffmpeg нужен в среде |
| Аудио (записи интервью) | на вход нужна расшифровка (сделанная вне агента, без ПДн) | Распознавания речи в репозитории нет |

## Исследование

- В демо веб не использовался: бриф учебный и самодостаточен, а пользователь попросил подтягивать веб только по
  обоснованию. Путь для веба реализован и закрыт политикой доменов.
- Данных оператора (частоты причин, отток, воронка) нет. Поэтому выводы держатся на допущениях с диапазонами
  и границей решения. Их проверка вынесена в план первого квартала.
- Модельные интервью дают формулировки и гипотезы, а не доли и спрос. Это ограничение закреплено в `sfp check`.

## Расчёты

- Экономическая модель упрощена: помесячное удержание, без сезонности и каннибализации тарифов.
  Чувствительность — только по сценариям «неблагоприятный / основной / благоприятный», без Монте-Карло.
  Исключение — расчёт α двух анализов.
- Стоимость человеко-месяца и трудоёмкость — допущения. До оценки командами окупаемость показана
  предельными вложениями.

## Поиск и память

- `sfp search` — TF-IDF по n-граммам: ловит словоформы, но не синонимы и не смысл.
  Для проекта на сотни записей этого хватает, для тысяч документов нужна векторная БД.
- Связи «утверждение → вывод → решение → абзац» строятся по ссылкам, которые расставил агент. Если агент не
  поставил ссылку, `sfp impact` этот абзац не найдёт. Частично это ловит `sfp check`: он находит ссылки на заменённые записи.

## Стоимость и время

- Токены в журнале — оценки, которые агент записывает в `sfp log`. Хук пишет каждое действие, но без токенов.
  Точные токены сессии — `/cost` в Claude Code; для субагентов среда сообщает их по завершении.
- Цены моделей — в `tools/pricing.json` (справочник API). При подписке на среду это оценка эквивалента, а не счёт.

## Windows

- CLI: `.\sfp <команда>` (обёртка `sfp.cmd`) или `python tools/sfp.py <команда>`.
- Хуки (`.claude/settings.json`) и MCP-сервер (`.mcp.json`) вызывают `python3`. На Windows такой команды обычно нет
  или её подменяет заглушка Microsoft Store. Тогда хуки не сработают: не будет статуса при старте, журнала инструментов
  и защиты доменов. Процесс при этом продолжится — агент сам выполнит `sfp status` по `AGENTS.md`.
  Исправление: в командах хуков заменить `python3 "…/hooks/X.py"` на `sh "$CLAUDE_PROJECT_DIR/tools/py.sh" "…/hooks/X.py"`
  (скрипт выбирает рабочий `python3`, `python` или `py`), а в `.mcp.json` — `python3` на `python`.
- Если кириллица в консоли отображается кракозябрами: `chcp 65001` (обёртка `sfp.cmd` делает это сама).

## Процесс и среда

- Хуки и субагенты есть только в Claude Code. В других средах те же шаги выполняет главный агент сам,
  и защиту обеспечивают `sfp check` и правила `AGENTS.md`, а не перехват вызовов.
- Агент не обходит защитные отказы среды. Например, удаление файлов с шаблоном пути он оставляет человеку.
- Демо пройдено одним сквозным прогоном. Шаги 01–05 выполнены в предыдущей сессии и продолжены в новой
  по `sfp status`, это и есть проверка продолжения после перерыва.
