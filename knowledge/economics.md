# Экономика: валовая прибыль, удержание, граница решения, окупаемость

## Базовая схема
`ВП(план. год, вариант) = ВП(без изменений) + вклад доп. оплаченных месяцев + другие доходы/экономия − новые прямые расходы`

Для каждого слагаемого — объём × цена × период. Одна база сравнения и один год для всех вариантов.

## Удержание → оплаченные месяцы
- Укажи, скольким номерам и **с какого месяца** станет доступна услуга.
- Для каждого следующего месяца: сколько продолжат платить при новом и при обычном обслуживании. Разница месяцев,
  попавших в плановый год, × ставка ВП за месяц.
- Работа, начатая в последнем месяце года, даёт в этом году максимум один дополнительный месяц на номер.
- Сокращение числа перебоев ≠ число оплаченных месяцев: нужна связь «перебой → отток» (гипотеза, проверяется по
  платежам исходных групп пилота, наблюдая номер и после выхода из группы).

Упрощённая формула для расчёта по месяцам:
`доп. месяцы = Σ_m N_m · (S_new(m) − S_old(m))`, где S — доля номеров, продолжающих платить к месяцу m.

## Другие пути
- **Экономия поддержки:** предотвращённые обращения × затраты, которые действительно исчезнут. Если время сотрудников
  высвобождается, а расходы те же — это не экономия денег; покажи, куда пойдёт время.
- **Платная услуга:** плательщики × цена − замещение уже оплачиваемых услуг − доля партнёра − обслуживание.

## Граница решения
При отсутствии других вкладов и новых расходов: `нужно доп. месяцев = разрыв / ставка`.
Для своего варианта найди величину ключевого параметра, при которой цель достижима, и покажи, что будет при более
слабом спросе, удержании или более высокой стоимости обслуживания. Если граница зависит от неизвестной цены —
дай формулу и назови значение, которое нужно узнать.

## Окупаемость
Стоимость разработки — отдельно. По кварталам: накопленная доп. ВП после прямых расходов vs накопленные вложения.
Пересечение = расчётный срок окупаемости. Пока стоимость разработки неизвестна — покажи **предельную сумму
вложений**, которая вернётся за выбранный срок. Деньги после конца планового года — в следующие годы.

## Долгосрочная ценность группы
Сравнивай группы одинакового размера. Для каждого периода: прибыль группы × вероятность продолжения обслуживания,
сумма по периодам. При нехватке данных об удержании — условный расчёт с явными допущениями.
