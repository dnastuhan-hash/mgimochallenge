# Маршрутизация: процесс → исполнитель → модель

Машиночитаемая версия: `tools/routing.json`; подсказка: `./sfp route "<задача>"`.

## Принципы
1. **Число считает Python, а не модель.** Любой расчёт — скрипт в `calc/`; модель пишет код и интерпретирует.
2. **Дешёвая модель — где ответ проверяется правилом или рубрикой** (извлечение, классификация, оценка по признакам,
   синтетические персоны). Ошибку ловит `sfp check` или `evaluator`.
3. **Сильная модель — где ценность в суждении**: варианты, возражения, стратегия, согласование.
4. **Исправление ошибочного выбора.** После шага `evaluator` (Haiku) оценивает результат по рубрике шага.
   Оценка < 0,75 → `./sfp route --escalate <модель>` → повтор шага моделью ступенью выше → запись в журнал.
   На верхней ступени — вопрос человеку (не хватает данных или постановки).
5. **Не повторять выполненное.** Перед делегированием — `sfp history` / `sfp search`.

## Таблица

| Задача | Навык | Исполнитель | Модель | Цена, $/1M ток. (вход/выход) |
|---|---|---|---|---|
| Извлечь текст/таблицы из файлов | materials | главный + `tools/extract.py` | haiku | 0,10 / 0,50 |
| Классификация, кодирование интервью | interview | evaluator | haiku | 0,10 / 0,50 |
| Оценка результата по рубрике | все | evaluator | haiku | 0,10 / 0,50 |
| Модельные респонденты | interview | synthetic-respondent | haiku | 0,10 / 0,50 |
| Исследование источников | research | researcher | sonnet | 2 / 10 |
| Расчёты, прогноз, выборка | validation, plan | analyst | sonnet | 2 / 10 |
| Разбор интерфейсов | ux-review | ux-reviewer | sonnet | 2 / 10 |
| Пересмотр при новых данных | revise | главный | sonnet | 2 / 10 |
| Варианты | options | главный | opus | 4 / 20 |
| Сильные возражения | options | red-team | opus | 4 / 20 |
| Стратегии и итоговый документ | strategy, deliverable | главный | opus | 4 / 20 |

Модели: opus = `claude-opus-5-5`, sonnet = `claude-sonnet-5-5`, haiku = `claude-haiku-5-5`. В frontmatter субагентов
Claude Code поле `model:` принимает `opus` / `sonnet` / `haiku` / `inherit`.

## Учёт стоимости
После каждого шага: `./sfp log "<шаг>" --model <модель> --tokens-in N --tokens-out M` (оценка по объёму прочитанного
и написанного; точные данные сессии — `/cost` в Claude Code). Сводка: `./sfp cost`.
