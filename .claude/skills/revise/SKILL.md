# Шаг 11б — Пересмотр при новых данных

1. Зарегистрируй новый материал (`source add`) и выпиши новые факты.
2. Для каждого прежнего утверждения, которое противоречит новым данным:
   - устарело/уточнено → `./sfp claim supersede C-00X --reason "…" --value … --sources S-…`
   - было неверным → `./sfp claim retract C-00X --reason "…"`
   Команда сразу показывает затронутое. Повтори `./sfp impact` для источника, если изменился файл.
3. `./sfp check` — список устаревших ссылок в документах и решений с устаревшими основаниями = **план правок**.
4. Пересчитай затронутые расчёты (скрипты в `calc/` с новыми параметрами). Обнови только затронутые разделы, замени
   ссылки на новые C-…. Не переписывай всё.
5. Запиши в документ раздел «Изменения от <дата>»: что пришло, что изменилось в выводах, что осталось в силе.
6. Если затронуто решение — `./sfp decision set D-00X --status revisit` и вынеси руководителю: сохранить / изменить / остановить.
7. `./sfp check` — 0 ошибок; `./sfp log "пересмотр: …" --kind action`.
