# Разбор интерфейсов и пути клиента

Методика: `knowledge/ux-review.md`. Исполнитель: субагент `ux-reviewer`.

1. Материал (скриншоты, видео-кадры, макеты) — в `sources/`, зарегистрирован `--kind media`.
2. Передай `ux-reviewer` пути к файлам и вопрос (какой путь, какая роль).
3. Результат — `work/ux_<тема>.md`: инвентарь экранов, путь по ролям, проблемы с привязкой («S-007, экран 2, …»),
   гипотезы «проверить в прототипе», предложение теста удобства.
4. Наблюдения — `fact` с источником media; интерпретации — `hypothesis`.
5. Если материала нет — путь из текстового описания с пометкой «интерфейс не анализировался».
