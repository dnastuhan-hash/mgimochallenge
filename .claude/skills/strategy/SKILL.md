# Шаг 07 — Продуктовая и коммуникационная стратегии

Методики: `knowledge/product-strategy.md`, `knowledge/comms-strategy.md`, `knowledge/economics.md`.

1. `./sfp stage 07_strategy in_progress`; проверь решение: `./sfp decision list`.
2. `work/07_product_strategy.md` — по шаблону (9 разделов). Путь клиента по ролям и одна операция до конца
   (включая повторное нажатие, ожидание подтверждения, отзыв согласия). Связь польза → поведение → деньги —
   расчёт `analyst` (`tools/calc/economics.py`), ссылки на forecast-утверждения.
3. `work/07_comms_strategy.md` — по шаблону: аудитории и ситуации, барьеры, сообщения и подтверждения, каналы.
4. **Таблица «обещание ↔ функция ↔ условие»** — обязательна. Каждое обещание связано с функцией из продуктовой
   стратегии. Обещание без функции — удалить.
5. Проверка согласованности (сделай явно, раздел «Согласованность» в comms): аудитория совпадает; барьер — тот,
   который снимает продукт; метрики коммуникации не выдаются за пользу; отказы продукта не обещаны в коммуникации.
6. `evaluator` по рубрике → при < 0,75 доработка.
7. `./sfp check` → `./sfp stage 07_strategy done --next "Шаг 08: план проверки"`

Рубрика: аудитория с размером рынка; альтернативы и преимущество; осознанные отказы; деньги с диапазоном;
барьер назван и типизирован; сообщение + подтверждение; роль каналов; все обещания в таблице.
