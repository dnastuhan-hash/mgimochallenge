# Шаг 01 — Постановка задачи

Методика: `knowledge/framing.md`.

1. `./sfp stage 01_framing in_progress`
2. Прочитай всё, что пользователь уже дал (сообщение, файлы). Не спрашивай то, что там уже есть.
3. Заполни карточку постановки в `projects/<id>/work/01_framing.md` (таблица из methodology). Пустые поля — либо
   вопрос пользователю, либо допущение (`./sfp claim add "..." --type assumption --verify "..."`).
4. Сформулируй **3–5 вопросов максимум**, каждый — только если ответ меняет следующий шаг. Для каждого:
   варианты ответа и твоё предложение по умолчанию.
5. Контрольная точка человека:
   `./sfp stage 01_framing waiting_human --note "подтвердить постановку и ответить на вопросы"`
   Покажи карточку кратко (5–8 строк) и вопросы. **Остановись.**
6. После ответа: `./sfp log "<суть ответа>" --kind human`, обнови карточку, зафиксируй факты из ответа
   (источник `--kind human`, зарегистрируй ответ как файл `sources/human_<дата>.md`).
7. `./sfp stage 01_framing done --next "Шаг 02: собрать и зарегистрировать материалы"`

Критерии готовности (рубрика evaluator): решение и срок названы; получатель и его критерий; цель в единицах и
периоде; ограничения; список доступных данных и известных пробелов; явные допущения.
