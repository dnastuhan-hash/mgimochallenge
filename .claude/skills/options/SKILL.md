# Шаг 05 — Варианты и сильные возражения → Шаг 06 выбор

Методики: `knowledge/options.md`, `knowledge/economics.md`.

1. `./sfp stage 05_options in_progress`
2. Сгенерируй 5–7 кандидатов по осям (кому / проблема / механизм / объём), отбери ≥3 содержательно разных
   + «оставить как есть» + «закрыть/заморозить» (если уместно).
3. Для каждого заполни карточку варианта (options.md). Деньги — расчёт `analyst` (`tools/calc/`), диапазоны.
4. **Возражения:** передай субагенту `red-team` только карточки вариантов (без своей рекомендации) и `04_situation.md`.
   Получи по 1–2 сильнейших возражения на вариант. Впиши их и свой ответ (или признание, что возражение верно).
5. Сравнительная таблица по одной ситуации и горизонту. Если дешёвый вариант почти равен дорогому — какое наблюдение
   оправдает дорогой. Если ни один нельзя обоснованно выбрать — самая короткая проверка, которая изменит решение.
6. Твоя рекомендация с основаниями `[C-…]` (`claim add --type inference --depends …`).
7. Проверка качества: субагент `evaluator` по рубрике ниже. < 0,75 → доработай (при необходимости — эскалация модели).
8. `./sfp stage 05_options done` и **контрольная точка**:
   `./sfp stage 06_choice waiting_human --note "выбрать вариант для пилота"`
   Покажи руководителю: таблицу (кратко), рекомендацию, главное возражение и что изменит решение. **Остановись.**
9. После выбора: `./sfp log "<выбор и комментарий>" --kind human`;
   `./sfp decision add "<решение>" --choice "<вариант>" --decided-by "<кто>" --owner "<ответственный>" --grounds C-…,C-… --status made`;
   `./sfp stage 06_choice done --next "Шаг 07: продуктовая и коммуникационная стратегии"`

Рубрика: ≥3 разных по оси варианта; есть «как есть»; карточки полные; возражения сильные и конкретные; деньги с
диапазоном и границей решения; факты отделены от прогнозов; рекомендация связана с основаниями.
