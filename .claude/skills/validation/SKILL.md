# Шаг 08 — План проверки

Методика: `knowledge/experiment-design.md`.

1. `./sfp stage 08_validation in_progress`
2. Метрики (3 уровня): польза для клиента, работа услуги, нежелательные последствия — числитель, знаменатель,
   единица, период, источник данных.
3. Дизайн: кого включать (условия возможности помочь), первый подходящий случай, единица рандомизации, сравнение.
4. Расчёт выборки и темпа набора — субагент `analyst`:
   `python3 tools/calc/sample_size.py --p1 … --p2 … --weekly … --weeks …` → результат в `calc/`, регистрация `--kind calc`.
   Если набора не хватает — варианты (длиннее набор / больший эффект / шире критерии / частая промежуточная метрика).
5. Порог решения и стоп-условия — **до запуска**. Что делать при каждом исходе (расширить / доработать / продлить / остановить).
6. `work/08_validation.md`; `./sfp check`; `./sfp stage 08_validation done --next "Шаг 09: план по кварталам"`

Рубрика: изменение измеримо; сравнение честное (ITT); выборка посчитана скриптом; темп набора проверен;
вред и стоп-условия; порог заранее; действия по исходам.
