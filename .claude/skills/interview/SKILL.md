# Интервью и модельные респонденты

Методика: `knowledge/interviews.md`.

## Гайд
`projects/<id>/interviews/guide.md` — цель, критерии отбора собеседников, вопросы о последнем реальном случае,
что запрещено спрашивать (гипотетика, наводящие).

## Реальные интервью
- Согласие собеседника; в репозиторий — без ПДн (Р1, Р2).
- Расшифровка → `interviews/real_R1.md` → `./sfp source add "Интервью Р1" --kind interview --path …`.
- Кодирование (может делать `evaluator`/haiku по кодовой книге) → таблица «случай × код» → утверждения с источником.

## Модельные респонденты
1. Карточки персон в `interviews/personas.md` (≥3, разные роли, включая скептика).
2. Для каждой персоны — субагент `synthetic-respondent`: передай карточку и гайд. Ответ сохрани в
   `interviews/synthetic_<персона>.md` (шапка «СИНТЕТИКА»).
3. `./sfp source add "Модельный респондент: <персона>" --kind synthetic --path …`
4. Из ответов — только `--type hypothesis` с `--verify` (как проверить на реальных людях/данных).
5. В документах пометка «(синтетическая гипотеза)». Никаких долей и «X % клиентов хотят».
