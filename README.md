# Конкурсные работы команды

В репозитории лежат **два задания**. Каждое — в своей папке, у каждого свой README с запуском и описанием.

| Папка | Задание | Что внутри |
|---|---|---|
| [`ИИ-проект/`](ИИ-проект/) | **ИИ-проект** | «Стратег Фабрики продуктов» — ИИ-агент для руководителя цифрового продукта (инструкции, знания, субагенты, CLI `sfp`). Демо-проект `family-connect` по брифу МегаФона |
| [`Вайб-кодинг/`](Вайб-кодинг/) | **Вайб-кодинг** | «Деканат Next» — работающий прототип личного кабинета студента («Цифровой деканат будущего»), собранный с ИИ-ассистентом |

## Как открыть

```bash
git clone https://github.com/dnastuhan-hash/mgimochallenge.git
```

**ИИ-проект:**

```bash
cd mgimochallenge/ИИ-проект
./sfp status
```

Подробнее — в [`ИИ-проект/README.md`](ИИ-проект/README.md). Итоговый документ: [`ИИ-проект/projects/family-connect/deliverables/strategy.md`](ИИ-проект/projects/family-connect/deliverables/strategy.md).

**Вайб-кодинг** — открыть без установки: **https://dnastuhan-hash.github.io/mgimochallenge/** (демо-версия, работает в браузере).

Запуск полной серверной версии:

```bash
cd mgimochallenge/Вайб-кодинг
npm install
npm start
```

После запуска кабинет открывается на http://localhost:3000. Тестовые аккаунты, безопасность и деплой описаны в [`Вайб-кодинг/README.md`](Вайб-кодинг/README.md). Исследование — [`Вайб-кодинг/docs/RESEARCH.md`](Вайб-кодинг/docs/RESEARCH.md), описание процесса — [`Вайб-кодинг/docs/PROCESS.md`](Вайб-кодинг/docs/PROCESS.md).

> Каждую папку открывайте в Claude Code или Cursor **как отдельный проект** (саму папку, а не корень репозитория). Тогда подхватятся её собственные `CLAUDE.md` и настройки `.claude/`.

Обе работы — концепты для конкурса. Все персональные данные в них вымышлены.
