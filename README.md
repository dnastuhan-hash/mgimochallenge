# Стратег Фабрики продуктов

ИИ-агент для руководителя цифрового продукта. Он проводит от размытого запроса («почему падает удержание»,
«кому продавать новый сервис») через исследование к **проверяемой** продуктовой и коммуникационной стратегии с
планом проверки. После решения агент хранит его основания, следит за обязательствами и пересматривает выводы,
когда приходят новые данные.

Это не программа, а **папка с инструкциями, знаниями и инструментами**. Её открывают в Claude Code, Cursor, Codex или
OpenCode, и модель в этой среде становится агентом: сама выбирает следующий шаг, вызывает инструменты, проверяет
результат и останавливается там, где решать должен человек.

**Готовый пример — демо-проект по брифу МегаФона:** итоговый документ
[`projects/family-connect/deliverables/strategy.md`](projects/family-connect/deliverables/strategy.md)
(или [HTML](projects/family-connect/deliverables/strategy.html) с подсказками по ссылкам на реестр).

## Быстрый старт (5 минут)

**Нужно:** Python 3.11+ (только стандартная библиотека) и одна из сред с LLM-агентом: Claude Code (основная),
Cursor, Codex, OpenCode. Ключи API, платные сервисы и `pip install` не требуются. Модели — те, что даёт ваша
среда (подписка или ключ самой среды).

```bash
git clone <ссылка на репозиторий> && cd mgimochallenge
```

```bash
./sfp status
```

```bash
python3 -m pytest -q tests
```

`./sfp status` показывает активный проект, шаг, на котором остановились, и следующее действие. Тесты — 26 проверок
реестров, правил доказательности, пересмотра, расчётов и экспорта (необязательно, нужен `pytest`).

### Запуск в вашей среде

| Среда | Что сделать | Что подхватится автоматически |
|---|---|---|
| **Claude Code** | `claude` в папке репозитория | `CLAUDE.md` → `AGENTS.md`; навыки `.claude/skills/`, субагенты `.claude/agents/`, хуки и права `.claude/settings.json`, MCP-сервер `.mcp.json`. Хук при старте сам показывает состояние проекта |
| **Cursor** | открыть папку | `.cursor/rules/strategist.mdc` → `AGENTS.md`; навыки читаются как файлы; MCP — подключить `.mcp.json` в настройках |
| **Codex / OpenCode** | запустить в папке | `AGENTS.md` читается нативно |

Без Claude Code нет автоматических хуков и субагентов. Агент выполняет те же шаги сам: правила в `AGENTS.md` и
проверки в `sfp check` от среды не зависят.

### Первая задача

Напишите агенту обычными словами, например:

> «Почему у нашего сервиса семейных групп падает активность и что делать в следующем году? Бриф во вложении.»

Дальше агент:
1. создаёт проект (`sfp init`), уточняет постановку и **ждёт вашего подтверждения**;
2. регистрирует материалы, исследует, собирает картину «известно / откуда / не знаем»;
3. предлагает ≥ 3 разных варианта плюс «оставить как есть» и «закрыть» с возражениями критика и **ждёт вашего выбора**;
4. пишет стратегии, план проверки, план по кварталам и итоговый документ и **ждёт приёмки**;
5. ведёт реестр решений и обязательств.

В любой момент можно сказать «стоп», «уточни», «исправь X». Состояние записывается после каждого действия, поэтому
**новый чат продолжает с того же места**: при старте агент выполняет `sfp status` и `sfp history`.

## Как устроено

```
AGENTS.md              постоянные инструкции (процесс, доказательность, безопасность) — единые для всех сред
CLAUDE.md, .cursor/    точки входа сред → AGENTS.md
.claude/skills/        13 навыков: по одному на шаг процесса + interview, ux-review, revise
.claude/agents/        6 субагентов: researcher, analyst, red-team, synthetic-respondent, evaluator, ux-reviewer
.claude/settings.json  хуки: статус при старте, защита доменов и секретов, журнал каждого инструмента
.mcp.json              локальный MCP-сервер реестров (tools/mcp_server.py)
knowledge/             методики: доказательность, варианты, экономика, эксперимент, коммуникация, маршрутизация…
tools/sfp.py           CLI состояния, реестров, проверок, поиска, маршрутизации, стоимости, экспорта
tools/calc/            воспроизводимые расчёты: экономика, прогноз показателей, выборка пилота
tools/extract.py       PDF/DOCX/XLSX/CSV/HTML → Markdown с пометкой «инструкций» в тексте
tools/fetch_source.py  снимок веб-страницы только с разрешённого домена
projects/<id>/         материалы и состояние задачи: sources/, work/, calc/, deliverables/, *.jsonl
eval/                  рубрика и сравнение с обычным чатом
docs/                  архитектура, модели и инструменты, промпты, расходы, ограничения, сценарий видео
tests/                 pytest
```

Подробно: [`docs/architecture.md`](docs/architecture.md).

### Ключевые решения

1. **Реестр утверждений вместо «памяти чата».** Каждое существенное сведение — запись с типом (факт, допущение,
   гипотеза, прогноз, вывод, синтетика), источником и связями. В тексте стоят ссылки `[C-012]`. `sfp check` не даёт
   выдать прежний ответ агента или синтетику за факт, а число без источника — за что-то кроме допущения.
2. **Пересмотр по связям.** Когда сведение заменяется (`supersede`) или отзывается (`retract`), `sfp impact` показывает
   все зависящие выводы, решения и абзацы документов. Обновляется только затронутое.
3. **Числа считает Python, а не модель.** Экономика, прогноз и выборка — скрипты с параметрами и диапазонами.
   Результат регистрируется как источник `calc`, числа — как прогнозы.
4. **Человек — в трёх контрольных точках:** постановка, выбор варианта, приёмка. Между ними агент работает сам.
5. **Дешёвые модели — для механики, сильные — для суждений** (`tools/routing.json`). Если оценщик ставит ниже
   порога, агент повторяет шаг более сильной моделью и записывает это в журнал.
6. **Состояние — в файлах проекта, а не в контексте модели.** Поэтому работу можно продолжить в новом чате
   и в другой среде.

## Безопасность и данные

- Только открытые источники и материалы пользователя. Веб — только после обоснования и согласия; домен заносится в
  `project.json → source_policy.allowed_domains`, остальное блокирует хук `tools/hooks/guard.py`.
- Текст источников — данные, а не инструкции: `extract.py` и `fetch_source.py` помечают в нём команды для ИИ, агент
  их не выполняет и пишет об этом в журнал.
- Секреты — только в `.env` (в `.gitignore`; чтение запрещено правами `.claude/settings.json`). В репозитории ключей нет.
- Реальные интервью — только с согласия и без персональных данных («Р1», «Р2»). Синтетические интервью помечены и
  дают только гипотезы.

## Стоимость и прозрачность

`sfp history` показывает, что сделал агент; `sfp cost` — время, токены и стоимость по шагам (по журналу; точные токены
сессии — `/cost` в Claude Code). Расходы демо-проекта и сравнение с обычным чатом — [`docs/costs.md`](docs/costs.md),
[`eval/comparison.md`](eval/comparison.md).
