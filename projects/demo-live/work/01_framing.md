# 01. Постановка задачи

Источник — бриф [S-001], [S-002]; первое разложение разрыва — расчёт [S-003].

| Поле | Содержание |
|---|---|
| Вопрос пользователя | Почему активных семейных групп 4 000 вместо 5 000 [C-001] и что делать в плановом году |
| Решение 1 и срок | **Конец Q1**: выделять ли людей и деньги на пилот [C-006] |
| Решение 2 и срок | **Конец Q2**, с финансами: расширять, менять предложение или наблюдать [C-006] |
| Получатель | Руководитель направления + финансовая команда; критерий — деньги, риск, обратимость [C-010] (допущение) |
| Цели планового года | Активные группы ≥ 8 000; подключённые ≥ 12 000; активация ≥ 60 %; ВП ≥ 285 млн руб. При «без изменений» — 5 000 / 8 000 / 45 % / 279 [C-005] |
| Отставание базового года | Активные 4 000 / 5 000 [C-001]; подключённые 6 500 / 7 500 [C-002]; активация 42 % / 50 % [C-003]; ВП 275 / 282 [C-004] |
| Первый взгляд на «почему» | ≈ 640 из 1 000 — меньше подключённых групп, ≈ 360 — ниже доля активных [C-008]. Где именно теряются группы — гипотеза: на принятии приглашения и первом действии [C-009] |
| Ограничения | Только открытые данные и материалы пользователя; числа учебные |
| Доступные данные | Бриф с итоговыми показателями. **Нет**: частот причин перебоев, историй клиентов, разбивки по каналам, помесячной воронки [C-007] |
| Горизонт | Плановый год по кварталам + ориентир на конец 3-го года |
| Вне рамок (предложение) | Цены тарифов целиком; владельцы нескольких номеров — только прогноз «без изменений», если не скажете иначе |

## Вопросы руководителю

1. **Рамки.** Только семейные группы (как в вопросе) или вся стратегия брифа, включая владельцев нескольких номеров?
   *По умолчанию:* фокус на семьях, по владельцам — прогноз «без изменений» и последствия.
2. **Данные.** Есть ли выгрузки сверх брифа (воронка групп по месяцам, обращения в поддержку, уходы)?
   *По умолчанию:* нет — работаем на допущениях с диапазонами и границами решения.
3. **Веб-источники.** Разрешить открытые источники (публичные описания семейных тарифов операторов) для альтернатив?
   *По умолчанию:* да, домены согласую перед загрузкой.
4. **Форма результата.** Полный документ из пяти частей по брифу или короткая записка «почему + что делать»?
   *По умолчанию:* полный документ, в начале — резюме на одну страницу.
