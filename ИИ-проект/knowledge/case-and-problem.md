# Клиент и его проблема

## 1. Выбери ситуацию, где действие оператора меняет результат
«Семьям нужен удобный кабинет» не объясняет, какая помощь нужна. Точнее: *кто первым замечает перебой, что пытается
сделать и в какой момент помощь уже запоздала*. Для владельца собственных устройств момент может быть другим —
например, день списания по номеру роутера.

## 2. Восстанови один случай (хронология)
Шаблон:

| Момент | Что произошло | Кто знал | Что мог сделать оператор |
|---|---|---|---|
| T−n | Последний момент, когда всё работало / остаток ещё был | … | Предупредить |
| T0 | Перебой / неожиданное списание | … | Объяснить причину |
| T+1 | Сигнал получен клиентом (какой? от кого?) | … | Дать действие в один шаг |
| T+k | Проблема разрешена (как? кто?) | … | — |

Ответь: какое последствие важно этому человеку (потерянный доступ, непонятное списание, время на выяснение);
**последний момент, когда оператор ещё мог помочь**. Если реальной истории нет — опиши, что спросишь у клиента
и какие записи оператора восстановят ход событий (события ограничения скорости, остатки, платежи, обращения).

## 3. Различи сигнал и причину
Сигнал «близкий не отвечает» не означает «закончился интернет». Версии и данные для их различения:

| Версия | Какие данные её подтверждают | Меняет ли предлагаемое действие |
|---|---|---|
| Закончилась доля пакета | остаток, событие ограничения, причина | да: выделить из свободного остатка |
| Неоплата | состояние счёта, результат платежа | да: пополнить/автоплатёж |
| Устройство выключено / разряжено | данные с устройства (нужны отдельно) | да: оператор не поможет без устройства |
| Связь есть, непонятно списание | детализация, подключённые услуги | да: объяснение начисления |

## 4. Обоснуй приоритет
Свяжи проблему с расхождением показателей (план/факт) и разбери возможные причины отставания: меньше пришло
клиентов / подключённые реже совершали полезное действие / номера раньше переставали приносить выручку.
Неизвестную связь обозначь как гипотезу.

Сопоставь выбранную проблему хотя бы с одной **серьёзной альтернативой** по признакам:

| Признак | Проблема A | Проблема B |
|---|---|---|
| У скольких разных клиентов возникает | | |
| Как часто повторяется | | |
| Тяжесть последствий | | |
| Доля случаев, где помощь возможна вовремя | | |
| Какие данные подтвердят | | |

Частый вопрос о начислении и редкий длительный перерыв связи требуют разных решений — объясни, какой ущерб важнее
предотвратить и почему.

## 5. Подбери сведения под вопрос
- История клиента → последовательность действий.
- Учёт обращений → с чем звонят (отдели повторные звонки об одном случае от новых; укажи период).
- Распространённость → данные и о тех, кто **не обращался**.

## 6. Заверши проверяемым предположением
«Если [действие] для [клиентов], то [метрика] изменится с X до Y за [срок]. Сменим приоритет, если [наблюдение].»
Значение до проверки — допущение; вместо одного прогноза — диапазон с обоснованными границами.
