# Рубрика оценки итогового документа

Используется субагентом `evaluator` (шаг 10) и для сравнения агента с исходным способом (`eval/protocol.md`).
Балл: 1 — выполнено и видно где; 0,5 — частично; 0 — нет. «О» — обязательный критерий (0 → доработка).

| id | Критерий | О |
|---|---|---|
| R1 | В начале: первые клиенты, выбранная проблема, предложение, ожидаемый результат | О |
| R2 | Картина ситуации: известно / откуда (ссылки) / не знаем и почему | О |
| R3 | Факты отделены от допущений, гипотез и прогнозов (типы видны) | О |
| R4 | Восстановлен один случай клиента; сигнал отделён от причины | |
| R5 | Приоритет проблемы сопоставлен с серьёзной альтернативой по частоте, тяжести, доле предотвратимого | |
| R6 | ≥3 содержательно разных варианта, включая «оставить как есть» | О |
| R7 | Для каждого варианта — сильное конкретное возражение и ответ | О |
| R8 | Продуктовая: аудитория и задача, альтернативы, направление, осознанные отказы | О |
| R9 | Путь клиента по ролям, согласия, одна операция до конца (повторное нажатие, ожидание подтверждения) | |
| R10 | Связь пользы с деньгами: расчёт с диапазоном, граница решения, окупаемость/предельные вложения | О |
| R11 | Коммуникационная: аудитория и ситуация, барьер, сообщение, подтверждение, роль каналов | О |
| R12 | Таблица «обещание ↔ функция ↔ условие»; обещаний сверх продукта нет | О |
| R13 | План проверки: метрика (числитель/знаменатель), сравнение, срок, выборка, темп набора, вред, порог заранее | О |
| R14 | Прогноз по всем строкам исходных показателей; разрывы до цели названы с ценой устранения | |
| R15 | План по кварталам с решениями; ориентир на 3-й год измерим | |
| R16 | Ресурсы, зависимости с ответственными и сроками; риски с признаками и действиями | |
| R17 | Конкретная просьба руководителю: что решить, сколько людей/денег, кто отвечает | О |
| R18 | Пробелы данных названы: что, почему, как получить, влияет ли на решение | О |
| R19 | Расчёты воспроизводимы (скрипт/формула рядом с решением) | |
| R20 | Синтетические данные не выдаются за реальные | О |
