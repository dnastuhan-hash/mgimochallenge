# Шаг 03 — План и проведение исследования

Методики: `knowledge/case-and-problem.md`, `knowledge/metrics-hygiene.md`, `knowledge/interviews.md`.

1. `./sfp stage 03_research in_progress`
2. **План от решения.** Выпиши 5–10 вопросов, ответ на которые может изменить выбор. Для каждого:
   | № | Вопрос | Как ответ меняет решение | Где взять ответ | Стоимость получения | Приоритет |
   Отбрось вопросы, которые не меняют решение («интересно, но не влияет»).
3. Для каждого вопроса по приоритету:
   - есть в материалах → ответ со ссылкой [C-…]/[S-…];
   - вычисляется → расчёт (субагент `analyst`, скрипт в `calc/`);
   - нужны внешние данные → обоснуй и спроси разрешения (не загружай сам);
   - нужен голос клиента → гайд интервью (навык `interview`); синтетика — только для гипотез;
   - нет и не получить сейчас → **пробел**: что / почему / как получить / влияет ли.
4. Восстанови один случай клиента (хронология, сигнал vs причина) — case-and-problem.md.
5. Сопоставь источники; при расхождении — запиши оба и объясни выбор.
6. Результат: `work/03_research.md` (план, ответы, расчёты, пробелы). Все утверждения — в реестре.
7. `./sfp log "исследование: N вопросов, M пробелов" --model sonnet --tokens-in … --tokens-out …`
8. `./sfp stage 03_research done --next "Шаг 04: картина ситуации"`

Критерии: вопросы связаны с решением; на каждый — ответ с источником или названный пробел; случай восстановлен;
сигнал отделён от причины; гигиена показателей соблюдена.
