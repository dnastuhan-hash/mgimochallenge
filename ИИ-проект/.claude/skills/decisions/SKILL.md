# Шаг 11а — Поддержка решений

Методика: `knowledge/decision-support.md`.

1. Для каждого принятого и предстоящего решения (из 09_plan): `./sfp decision add … --owner … --grounds … --metric … --review-by YYYY-MM-DD --trigger "…"`.
2. Обязательства (зависимости, работы): `./sfp decision commit D-00X "<что>" --owner "<кто>" --due YYYY-MM-DD`.
3. В начале каждой сессии на этом шаге: `./sfp check` и `./sfp decision list`; покажи руководителю:
   - что решать сейчас (наступившие сроки, сработавшие триггеры);
   - какие основания устарели (заменённые/отозванные C-…);
   - просроченные обязательства и их влияние на прогноз.
4. Статусы обновляй `./sfp decision set D-00X --status … | --commitment N --commitment-status done`.
