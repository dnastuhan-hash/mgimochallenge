# Воспроизводимые расчёты

Все скрипты — стандартная библиотека Python 3.11+, параметры отдельно от кода (`projects/<id>/calc/params.json`),
результат — `*_out.md` (для чтения) и `*_out.json` (для проверки). Формат параметров — `example_params.json`.

| Скрипт | Что считает |
|---|---|
| `economics.py` | Доп. оплаченные месяцы по потокам (удержание, новые номера, предотвращённые остановки, прочие доходы) → валовая прибыль год 1–3, разрыв до цели, граница решения, чувствительность, окупаемость и предельные вложения |
| `forecast.py` | Собственный прогноз по строкам исходной таблицы показателей (выражения над параметрами) в трёх сценариях |
| `sample_size.py` | Выборка для сравнения двух долей, эффект дизайна (рандомизация семьями), темп набора, обнаружимый эффект |

```bash
python3 tools/calc/economics.py   --params projects/<id>/calc/params.json --out projects/<id>/calc
python3 tools/calc/forecast.py    --params projects/<id>/calc/params.json --out projects/<id>/calc
python3 tools/calc/sample_size.py --params projects/<id>/calc/params.json --out projects/<id>/calc
```

Правила: у каждого допущения — диапазон `low/high` (иначе скрипт откажется считать), `source` — ссылка на
источник или обоснование границ; `better: lower` для затрат; `max` — физический предел (доля ≤ 1).
Сценарии берут **все** допущения с неблагоприятного/благоприятного края одновременно — это намеренно широкая вилка;
вклад каждого допущения по отдельности показывает таблица чувствительности.
