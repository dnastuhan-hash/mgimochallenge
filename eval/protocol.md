# Протокол сравнения с исходным способом

**Вопрос:** насколько агент лучше обычного чата с ИИ на той же модели и какой ценой.

## Условия

| | Агент | Обычный чат (эталон) |
|---|---|---|
| Модель | Claude Opus 5.5 (главный) + субагенты по `routing.json` | Claude Opus 5.5 |
| Вход | бриф `projects/family-connect/sources/brief.md` | тот же бриф, **только он** |
| Процесс | 11 шагов, реестры, расчёты, критик, оценщик, 6 реплик человека | один запрос: «подготовь продуктовую и коммуникационную стратегию с планом проверки… один документ» |
| Результат | `projects/family-connect/deliverables/strategy.md` | `eval/baseline/strategy_baseline.md` |

Эталон запускался субагентом с запретом открывать другие файлы репозитория и ходить в веб.

## Оценка

1. Копии документов без имён: `eval/blind/doc_A.md` (эталон), `eval/blind/doc_B.md` (агент).
2. Два оценщика разной силы (haiku и sonnet) с одним промптом. Каждый оценивает оба документа независимо:
   - по рубрике `eval/rubric.md` (R1–R20, 1 / 0,5 / 0, с цитатой-основанием);
   - по чек-листу ошибок E1–E6, выбранных заранее: число без пометки как факт; синтетика или частота как
     установленные; раскрытие баланса без отдельного доступа; не проверен темп набора; обещание закрыть разрыв ВП;
     внутренние противоречия.
3. Оценщикам доступны только два документа, бриф и рубрика.

## Как повторить

1. Запустить эталон: тот же запрос к модели в обычном чате, приложив только бриф.
2. Скопировать оба документа в `eval/blind/` под нейтральными именами.
3. Дать субагенту `evaluator` (или любой модели) промпт из раздела «Оценка». Текст промпта — в
   `eval/comparison.md`, приложение.

## Ограничения (важно)

- **Слепота неполная.** Документ агента узнаётся по ссылкам `[C-…]`, а оценщики — модели того же семейства.
- **Рубрика наша.** Агент проверял свой документ оценщиком по этой же рубрике и дорабатывал его, то есть
  «готовился к экзамену». Чек-лист E1–E6 эту предвзятость снижает: это конкретные ошибки по брифу, а не стиль.
- **Один прогон эталона.** Разброс между прогонами не измерен.
- Время и токены эталона — по данным среды о субагенте; у агента — по журналу (см. `docs/costs.md`).
